2. 我们收集的信息

视您使用 Flowora 的方式，我们可能处理下列类别的信息。我们不会出售您的个人信息。

您首次启动并点击「同意」本政策前，本应用及第三方 SDK 不会收集软件安装列表、Android ID、OAID、IMEI、IMSI、设备 MAC 地址、位置等个人信息；同意后亦仅在实现对应功能所必需时收集。

  • 账号与身份：微信登录标识、昵称、头像 URL，以及维持登录状态所需的会话令牌。
  • 监督关系数据：您的 6 位监督码、邀请、您为监督人设置的昵称/头像，以及关系状态（「监督我的人」/「我监督的人」）。
  • 应用锁定配置：锁定规则、时间表、时长限制、所选应用令牌/标识符、您选择的解锁密码或验证输入，以及执行状态。
  • 软件安装列表：在您使用「选择应用 / 应用锁」功能时，通过系统 PackageManager 查询本机可启动应用列表（含应用名称、包名与图标），用于配置锁定目标；不会在您同意本政策前读取。
  • 本机安装标识（installId）：应用在同意本政策后于本机生成的随机标识，用于匿名建户与会话恢复；非 IMEI / IMSI / MAC 地址。
  • 您创建的 Safebox 内容：私人笔记、私人联系人（您输入的姓名/电话/邮箱），以及您导入的私人照片/视频。上述内容主要为您使用 Safebox 功能而存储。
  • 锁定所需的使用与设备信号：在 iOS 上，Screen Time / FamilyControls、DeviceActivity 与 ManagedSettings 授权及相关令牌；在 Android 上，无障碍服务事件与使用情况访问（PACKAGE_USAGE_STATS），用于检测前台应用并施加屏蔽。前述使用情况访问仅在您开启相关权限且使用锁定功能时发生。
  • 会员与商业数据：VIP/会员状态、到期时间，以及通过应用内支付流程处理的购买相关记录。
  • （Android）国内版会员购买通过微信支付完成；我们处理订单号、支付结果与会员履约状态等必要信息。支付收银台内的银行卡等敏感信息由微信按其隐私政策处理，本应用不采集。
  • 广告互动数据：当您通过广告聚合合作伙伴（GroMore / Pangle 技术栈）观看激励广告（例如免费锁定时长奖励）时，可能处理广告投放所需的设备与广告事件信号。本应用不请求 App Tracking Transparency，亦不将数据用于跨其他公司的 App 或网站跟踪用户。
  • 您提交的反馈：消息内容、可选联系方式与时间戳。
  • 本地偏好：语言、小组件配置等存储于设备本地的设置（例如通过本地数据库 / SharedPreferences）。
  • 技术日志：有助于保障服务稳定的基本诊断信息，例如 API 错误或执行失败。此类信息不会用于广告画像。

3. 我们申请的权限

Flowora 仅在功能需要时申请系统权限。您可在系统设置中拒绝或撤销权限；部分功能届时将不可用。

  • Screen Time / FamilyControls（iOS）：选择应用/类别，并为时间限制与锁定施加屏蔽。
  • 无障碍与使用情况访问（Android）：检测前台应用并持续执行锁定。
  • 悬浮窗（Android）：在部分机型上展示锁定遮罩页。
  • 忽略电池优化（Android）：保障锁定拦截在后台持续生效。
  • 开机相关（Android）：开机后检测无障碍服务是否仍开启（详见「自启动与关联启动」）。
  • 前台服务与精确闹钟（Android）：有锁规则时保活进程，并准时执行锁定（详见「自启动与关联启动」）。
  • 通知与全屏通知（Android）：提醒锁定状态，并在需要时拉起锁定/解锁页。
  • 照片与视频图库：选择个人头像与监督人头像；为意见反馈添加图片。
  • 照片与视频图库（Android）：将照片/视频导入 Safebox；确认后可删除图库原件。
  • 网络访问：登录、数据同步与激励广告等联网功能。
  • 主屏幕小组件 / App Groups：使用共享本地数据展示小组件内容（系统刷新小组件时可能短暂拉起本应用进程，详见「自启动与关联启动」）。

自启动与关联启动（Android）

为保障应用锁定在系统清理后台后仍可生效，本应用（Android）可能在您同意本隐私政策之后，于下列合理场景下发生自启动或关联启动（含进程被系统或小组件框架短暂拉起）。我们不会在您同意本政策前启用下述行为；亦不会在无对应功能需求时无故频繁拉起。

  • 场景与目的：您已创建并启用限时锁 / 手机锁等锁定规则时，为重绑无障碍服务、检测前台应用并展示锁定页，可能通过开机广播、精确闹钟与前台服务进行保活；开机后若发现无障碍被系统关闭，可能发通知引导您重新开启。
  • 桌面小组件：若您已将「限时锁」小组件添加到桌面，系统或小组件框架（含 androidx.glance.appwidget 相关组件）在更新卡片内容时，可能短暂启动本应用进程；目的仅为展示您配置的锁任务预览，不用于广告或与锁定无关的关联启动第三方应用。
  • 规则与必要性：仅在有锁定规则和/或您已添加桌面小组件等合理场景下启用；无锁定规则时停止保活看门狗。上述能力为实现「清退后仍能拦截被锁应用」所必需；您可在系统设置中限制自启动，或撤回隐私同意后停止相关行为。
  • 同意要求：首次启动并点击「同意」本政策前，本应用不会基于锁定保活目的主动自启动或关联启动；同意后仅在上述场景下依法产生相关行为。

5. 本地处理与云端同步

Flowora 的许多敏感功能依赖端侧机制：iOS 上的 Screen Time 框架、Android 上的无障碍/使用情况统计，以及用于规则与 Safebox 内容的本地 SQLite 存储。

账号、监督关系、会员状态及其他服务功能可能与我们的后端服务器同步，以便在与您登录关联的会话与设备间正常工作。我们仅传输上述功能所需的信息。产品信息发布于 https://global.haloutongxue.com/discipline.html。

我们不会声称读取您锁定的第三方应用内容。锁定使用平台令牌/软件包标识符与系统 API，而非截屏或完整抓取其他应用内容。

8. Safebox、媒体与敏感内容

Safebox 用于存放个人私密内容。您自行决定导入内容。请勿存储您无权合法持有的内容。

（Android）若您授权在导入后从系统相册删除原件，该操作将按您的请求执行。确认删除前请备份重要媒体。

Safebox 密码保护是产品安全功能，并不能保证在设备被入侵、越狱/Root、取证提取，或他人已知您的解锁方式时仍绝对安全。

9. 儿童与家庭使用

Flowora 可用于个人自律或相互监督。若您与儿童一起或为儿童使用本应用，您有责任依据适用法律取得所需同意，并合理配置监督。

我们不会在知情情况下将本应用营销为以广告为目的收集儿童个人数据的服务。家长或监护人应在儿童设备上启用锁定或媒体功能前审阅权限。

10. 数据保留

在您的账号保持有效且为提供服务所需期间，我们保留账号与关系数据。本地 Safebox 与锁定配置会保留在您的设备上，直至您删除、清除应用数据或卸载本应用（受操作系统备份行为影响）。

在法律、会计或安全原因要求时，我们可能更长时间保留有限记录（例如购买历史、防欺诈日志或反馈）。
