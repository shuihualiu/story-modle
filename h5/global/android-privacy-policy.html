隐私政策

中国大陆国内版 · Android

欢迎使用「一起做计划」！我们非常重视您的个人信息和隐私保护。本隐私政策旨在向您说明我们如何收集、使用、存储和保护您的个人信息，以及您所享有的相关权利。请在使用本应用前，仔细阅读并充分理解本政策的全部内容。

本应用由杭州哈喽同学网络科技有限公司开发并运营。

本政策生效日期：2026年9月28日
本政策最近更新日期：2026年9月29日

一、我们收集的信息
1. 账号信息：当您通过微信授权注册或登录时，我们可能会收集您的昵称、头像、OpenID、UnionID 等微信授权信息，用于创建账号、识别用户身份及展示个人资料。
2. 使用数据：包括您在应用中的使用情况，如创建的计划、任务、日程、纪念日、习惯打卡、专注记录、偏好设置、常用功能等，用于为您提供核心功能和个性化服务。
3. 设备信息（目的、方式、范围）：
   （1）设备型号、操作系统版本、应用版本号、网络连接状态（如是否联网）：用于界面适配、保障服务安全与稳定。
   （2）极光推送 Registration ID、应用包名与版本：仅在您同意本隐私政策后，由极光推送（JPush）SDK 生成/读取，用于远程推送通道；我们会将 Registration ID 上报至应用服务端。计划到点提醒由本机本地通知与闹钟实现，不通过极光推送。
   （3）我们已通过极光采集控制关闭 IMEI、IMSI、设备 MAC 地址、已安装应用列表、精确地理位置、基站信息、Wi‑Fi 相关信息（含 SSID/BSSID/Wi‑Fi 状态）等扩展采集，并在应用清单中移除定位、电话状态、蓝牙、帐号、任务列表、应用使用统计、Wi‑Fi 状态等非推送必需权限。极光推送 SDK 为建立推送通道可能另行使用的设备标识，以其公示的隐私政策为准。
4. 日志信息：当您使用本应用时，我们可能会记录相关日志信息，例如访问时间、错误崩溃信息等，用于优化产品和排查问题。
5. 图片与媒体：您主动上传的头像、计划配图、纪念册图片等；选取图片时通过系统相册选择器仅获取您当次选中的文件，不申请读取全部照片/媒体库权限。
6. 收货信息：当您在「地址管理」或领取盲盒公仔等实物奖品时主动填写，我们可能收集收货人姓名、联系电话、收货地址。
7. 支付信息：当您通过微信支付购买会员、贯币等付费服务时，我们可能处理订单号、商品信息、支付金额与支付状态等信息；支付密码、银行卡号等敏感支付凭证由微信支付处理，我们不会收集。

重要提示：在您首次启动并点击「同意」本隐私政策之前，不会初始化极光推送（不调用 JPush init），亦不会初始化其他需在同意后启动的网络侧 SDK。

二、我们如何使用信息
1. 提供基础功能：例如数据同步、任务管理、提醒通知、统计分析等，以保证应用核心业务的正常运行。
2. 提升产品体验：通过分析匿名的使用数据，优化功能设计和交互流程，改进性能和稳定性。
3. 安全保障：用于身份验证、安全防护、反作弊、异常检测，保护您的账号和数据安全。
4. 消息通知：计划到点提醒通过系统本地通知与闹钟实现。在您同意本隐私政策，并获得通知权限授权后，我们可能通过极光推送（JPush）向您发送分享加入等远程服务通知。您可随时在「我的 → 权限管理」或系统设置中关闭通知权限。
5. 交易履约：用于完成会员、贯币等付费购买、订单查询与权益开通。

三、信息的存储与保护
1. 存储方式：我们会依据法律法规的要求，将您的个人信息存储在具备安全保护能力的服务器中，并采取加密、访问控制等措施。
2. 存储期限：我们仅在实现本政策所述目的所需的最短期间内保存您的个人信息；当超出必要期限或您申请注销账号后，我们会根据法律法规的要求进行删除或匿名化处理。
3. 安全措施：我们会采用合理可行的安全防护手段防止信息的丢失、滥用、未经授权访问或泄露，但也请您妥善保管账号和设备，避免账号被他人使用。

四、我们如何共享、转让和公开披露信息
1. 共享：除非获得您的明确同意或另有法律法规规定，我们不会与任何第三方共享您的个人信息。若确有必要与合作伙伴共享，我们会对信息进行去标识化处理，并与其签署严格的保密协议。第三方共享详情请参阅应用内「第三方共享清单」。
2. 转让：我们不会将您的个人信息转让给任何公司、组织或个人，除非取得您的授权，或发生合并、分立、重组等情形且信息接收方继续受本政策约束。
3. 公开披露：除非依据法律法规或行政、司法机关的强制要求，我们不会公开披露您的个人信息。

五、您的权利
在法律法规允许的范围内，您对自己的个人信息享有以下权利：
1. 访问和更正：您可以在应用内查看和修改个人资料、账号信息等。
2. 删除：在符合法定条件的情况下，您可以请求我们删除特定的个人信息。
3. 撤回授权：您可在「我的 → 权限管理」关闭通知等系统权限，或通过系统设置撤回授权；撤回后可能影响对应功能。
4. 注销账号：您可在「我的 → 账户信息 → 注销账号」申请注销。确认后我们将删除云端账号及相关个人信息，并清除本机登录态；法律法规另有留存要求的除外。

六、未成年人保护
本应用主要面向成年人用户。若您是未满18周岁的未成年人，应在监护人同意和指导下使用本应用及相关服务。
